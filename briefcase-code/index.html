Grounded 2 Briefcase Code Guide

The Grounded 2 briefcase uses two fixed three-digit codes. Find the case on the north bench of the Picnic Table, then use the route and code clues below.

Quick answer

Left lock: 137

Right lock: 514

The code is reported as fixed across worlds by the checked guide sources.

Where is the briefcase?

It sits on the north bench of the Picnic Table, just north of the Snackbar area in Brookhollow Park.

Open Brookhollow Park map

How to reach the briefcase

  1. Go to the Picnic Table and start from the tablecloth on the south side.
  2. Move under the tablecloth, then use the boxes and wooden mallet to cross toward the opposite bench.
  3. Reach the north bench, interact with the briefcase and enter 137 on the left dial and 514 on the right dial.
Code clue 1

137 on the picnic table

The first number is written near the crossword section of a newspaper on top of the Picnic Table.

Code clue 2

514 on the podium

The second number is written on a torn paper at the top of the podium in the Ceremony region.

Rewards

The checked guides report 500 Raw Science, one Milk Molar, Fresh Mints, Spicy Candies and Sour Candies inside the briefcase. Some candy pickups require the corresponding Omni-Hammer level.
