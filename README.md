# Grounded 2 Guide Hub

An unofficial, static English guide site for Grounded 2 key item locations and puzzle guides.
The first focused guide is the Milk Molar Finder for Brookhollow Park.

Pages included:

- Home: `/`
- Wiki navigation: `/wiki/`
- Map page: `/map/`
- Milk Molar locations page: `/milk-molars/`
- Briefcase code page: `/briefcase-code/`
- Updates page: `/updates/`

Run locally:

```bash
python3 -m http.server 4175
```

Then open `http://127.0.0.1:4175/`.

## Notes

- The site links to the official Grounded 2 site and third-party browser maps for verification.
- The supplied map image in `assets/grounded2-map-reference.jpg` is a visual reference. Confirm image rights before commercial publishing or monetization.
- Coordinate data is kept as secondary reference data; route claims should be checked against current game footage or a live map.
